# USHSO Question-to-Data Discovery Benchmark v0.1.0

This is the offline Lane O3 benchmark package. Run npm test for fixture-first tests and npm run validate for package validation. Build is deterministic and reads only existing local project metadata/evidence records.

The package contains exactly 60 structured questions, source-bound relevance judgments, coherent bundle goldens, answer plans, deterministic splits, metric definitions, review items, schemas, valid/invalid fixtures, a design report, a manifest, and a validation report. It does not implement retrieval or perform external requests.
