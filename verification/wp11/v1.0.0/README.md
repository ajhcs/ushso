# WP11 verification v1.0.0

This package seals the local WP11 public UI foundation. It proves the canonical-plan renderer, bounded export, researcher decision aids, WP9 coverage projection, mode separation, disabled planner adapter seam, and canonical public-HTTPS navigation boundary for untrusted evidence URLs. That boundary rejects credentials, secret-bearing query keys, local/private destinations, controls, ambiguous syntax, and overlong URLs before a rendered sink can use them. It does not authorize or claim a planner compiler, `/api/plan`, contract endpoint, coverage-copy publication, production deployment, or completed human usability review.

Run from the repository root after the web commands have passed:

```text
npm test --prefix apps/web
npm run typecheck --prefix apps/web
npm run build --prefix apps/web
npm run verify --prefix verification/wp11/v1.0.0
npm test --prefix verification/wp11/v1.0.0
npm run validate --prefix verification/wp11/v1.0.0
```

The two governance packets remain pending until independently reviewable aggregate-only human study receipts exist.
