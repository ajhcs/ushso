# Evidence ingestion

Validated receipts under `receipts/` can change **calculated** observation and attempt-ledger results.

They cannot:

- set `accepted`
- grant scientific approval
- invent 8+8 participants, 14 elapsed days, two scheduled cycles, AT/browser captures, C-009-1 topology, or production rollout
- treat fixture observation as R15
- rewrite frozen `evaluation/research-program/cohorts.json`

Previous failed snapshots are retained in `history/`. Integrated PR count does not close remediation tasks in `verification/research-program/remediation/`.

Receipt kinds: `observation_window`, `scheduled_cycle`, `attempt_axis`. Each receipt must bind `evidence_reference` + SHA-256 of exact bytes inside the repository.
