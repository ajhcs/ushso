## Atomic commits

### C-067-1 — Define a versioned shortlist record

**Verify:** No credentials or source payloads enter local storage; private notes are never automatically sent to enrichment or telemetry.

### C-067-2 — Implement add/remove and restore

Add visible controls on results/detail and a workspace list using canonical IDs. Detect unavailable or changed generations on reload.

**Verify:** Duplicate clicks do not duplicate a source; stale entries retain their original context and offer explicit refresh.

### C-067-3 — Support accessible shortlist management

Provide keyboard operations, status announcements, empty state and count. Link each selection back to its exact source context.

**Verify:** A user can select sources, navigate away, return and deliberately clear the list on desktop/mobile.
