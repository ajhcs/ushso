## Atomic commits

### C-051-1 — Model inline and external references

Scope provider-group/reference IDs to the reporting file/version and preserve NPI/TIN type/value as documented. External references are separate bounded resources.

**Verify:** Equal numeric reference IDs in different files cannot be joined accidentally.

### C-051-2 — Resolve bounded reference closures

Fetch/parse only the required declared reference objects under source budgets; detect missing references and cycles without unbounded expansion.

**Verify:** A missing referenced object yields an unresolved association; no provider group is invented from a hospital name.

### C-051-3 — Expose reference completeness

Attach resolved/unresolved group counts, context and evidence to the rate sample. Keep facility mapping a separate qualified join.

**Verify:** An NPI-bearing rate does not automatically map to a hospital CCN or a complete facility roster.
