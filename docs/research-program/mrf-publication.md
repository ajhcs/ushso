# MRF directory profiles

Policy version: `ushso.mrf-repository.v1`.

A profile can explain a blocked file without claiming a sample exists. Separate files/releases retain stable identities. A query for negotiated rate files does not lead with enforcement outcomes as a compatible file. Counts represent hospitals/reporting entities/files separately; shared files do not inflate provider coverage. An MRF sample is not a complete hospital or payer publication.

Sealed search lifecycle and coverage accounting are not edited. Last-good generation remains `live-2026-09-03-85b50522b420`.
