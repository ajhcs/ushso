# Research example packets

Policy version: `ushso.research-example-packet.v1`.

A research example packet includes the question, selected products/releases, why each is needed, fields, access steps, tested request, supported join routes, caveats, and citations.

A packet is invalid if its source/schema generation differs from an attached request or result. Every executed step has a receipt. A documented but unexecuted step is visibly labeled. Unavailable restricted steps stay labeled unavailable.

Expected output is a field/type shape, not a fragile numeric constant. A changed source schema invalidates the example and preserves its previous dated version. No live data is fabricated for a demo.
