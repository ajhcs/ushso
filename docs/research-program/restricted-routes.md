# HCUP, MEPS and AHA access workflows

Policy version: `ushso.access-workflow.v1`.

Restricted, paid and public products have useful next steps without false access claims. Public MEPS files are not labeled restricted solely because another MEPS product is restricted. AHA terms are not inferred.

Each workflow step cites a source. Undocumented fees or eligibility remain unknown. USHSO never collects a user's eligibility or credentials. An agent can explain the next legitimate step and cannot claim a successful restricted-data download.

Catalog, license and payload access remain separate dimensions. Sealed `packages/identity/src` is not edited; workflow cards live under `packages/connectors/source-registry/`. Last-good generation remains `live-2026-09-03-85b50522b420`.
