# Source cards

Policy version: `ushso.source-card.v1`.

A source card requires purpose, coverage, grain, example variables, access steps, tested state, limits, and citation. Documented use, reviewed recommendation, and unsupported use are separate.

A card cannot declare Best for from topic tags alone. Missing essential facts produce an explicit incomplete status. Each source-claim sentence resolves to evidence and a publisher passage a reviewer can compare. Exact release/schema/example IDs and beginner/expert guides are attached. Material limitations are retained; unknowns stay compact rather than full page sections.

Sealed `packages/identity/src/researcher-guidance.mjs` is not edited by this implementation. The web helper refuses topic-tag Best for.
