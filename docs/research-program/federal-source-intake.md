# Federal source-family intake

Policy version: `ushso.federal-source-intake.v1`.

HRSA AHRF, NPPES, SAMHSA facility services, CMS T-MSIS/TAF, and CDC/ATSDR SVI have evidence-backed intake dispositions. Every locator is publisher-supported.

TAF restricted research files are not public Medicaid summary products. Adding a route never asserts access to restricted TAF data. Each family has a literal configuration and fixture. An unsupported protocol produces a specific extension task rather than a custom unbounded scraper.

Original NPPES/AHRF/SAMHSA/SVI questions identify the intended family. Exact restrictions remain visible. Catalog membership is not invented. NPI is not CCN. Synar tables are not facility-services data. ASPE catalog SVI is not ATSDR SVI.
