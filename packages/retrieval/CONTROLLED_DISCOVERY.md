# Controlled discovery successor

`POST /api/discovery-controls/v1/search` accepts `ushso.controlled-discovery.input.v1`: `query` follows the unchanged discovery-query contract; optional `intent_override` replaces inferred `subjects`, `geographies` and `observation_years`. Lists contain controlled IDs. An explicit empty list removes that inferred dimension. Observation years are either `{start,end}` (both integer years, 1800–2200, start <= end) or `null` to remove inferred years. Omitted override fields retain inference. Unknown IDs, fields and inverted or incomplete ranges fail validation. Original question remains in the response; replaced dimension spans are excluded from lexical scoring, rather than reintroduced as essential words.

`coverage_mode` is `all`, `verified_only` or `unresolved_only`. The response wraps the unchanged discovery-result object under `discovery`, with `interpretation_provenance` and `coverage_filter`. Counts cover all matches after other filters and before coverage selection/pagination: before, included, excluded, verified and unresolved. Verified plus unresolved equals before; included plus excluded equals before. All four quantities are record counts, not source fitness or availability claims.

Verified coverage requires geography state `verified_first_party`, preserved IDs referencing first-party evidence, and dimension-scoped evidence `scope={subject_record_id,dimension:'geography',value:{coverage_level,jurisdictions}}` matching the exact record and asserted value. Generic catalog-presence evidence does not qualify. Requested regions require explicit membership; national coverage alone cannot confirm state coverage. When years are requested, a verified observation period and scoped `dimension:'observation_period',value:{start,end}` evidence must cover the full interval. Dates must be a valid year or real ISO date. Unknown, inferred, malformed or unscoped observations remain unresolved. These fields do not promote inventory into an accepted ledger or create evidence; current published inventory can legitimately have zero verified matches.

The continuation binds catalog generation, ranking version, original/effective query, overrides, coverage mode, other filters, sort and page size. Ranking changes invalidate prior cursors; restart preserves visible input. Invalid or mismatched continuations are typed restart errors, unavailable generations remain typed unavailable, and transient failures are not empty success. Worker request time controls freshness, matching ordinary discovery.

The original `/api/discover` input contract remains unchanged and rejects the new override fields. UI controls use this successor only after explicit application; clearing corrections returns to ordinary automatic interpretation. Source acquisition, paid calls and planning remain disabled. Existing browser cursor integrity is noncryptographic; this successor does not claim a secret-key signature.
